# Taller Materia · prototipo

Prototipo navegable del sitio de Taller Materia: piezas de artistas locales, kits con tutorial, art-box mensual, talleres, exposición digital y encargos.

**Estado:** prototipo v0.1. Fotos, artistas, precios y textos son de ejemplo. El carrito, el pago y los formularios no envían ni cobran nada.

## Cómo verlo

- **En línea:** https://coticocodrila.github.io/taller-materia/ (una vez activado GitHub Pages).
- **En tu computador:** descarga el repositorio (botón verde *Code* → *Download ZIP*) y abre `index.html` en el navegador.

## Qué hay en cada archivo

| Archivo | Qué contiene |
|---|---|
| `index.html` | Estructura fija: aviso de prototipo, menú, footer y carrito. |
| `css/estilos.css` | Colores, tipografía (Archivo) y diseño. Los colores están arriba, en `:root`. |
| `js/datos.js` | **Contenido de ejemplo**: artistas, piezas, kits, tutoriales, talleres y planes del art-box. Para cambiar un texto o un precio, edita aquí. |
| `js/app.js` | Páginas, navegación y carrito. |
| `img/` | Logo. Aquí irán las fotos reales. |
